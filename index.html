Proposta de redesign · Área de Cases

CASES

Hoje a página mostra só os vídeos e o crédito de quem filmou. A proposta é transformar cada case em uma história com contexto, resultado e emoção, mantendo a estética da Allmana e tudo o que o Wix Studio permite fazer.

Este é um protótipo de conceito. Os títulos, textos, números e categorias são exemplos ilustrativos para serem substituídos pelos dados reais de cada evento. As imagens são capas reais já usadas no site da Allmana.

Grid editorial com filtros

Cada card ganha categoria, cliente, nome do case e local/ano. No topo, filtros por tipo de evento. Ao passar o mouse, aparece o resultado em destaque.

VIABILIDADE

Como isso fica no Wix Studio

Tudo aqui usa recursos nativos do Wix Studio. Nada depende de código externo pesado. A base é um único lugar para cadastrar os cases (CMS), e o resto se monta sozinho.

Um cadastro de cases (CMS)

Uma coleção no CMS do Wix com os campos de cada case: capa, vídeo, categoria, cliente, local, ano, números e textos. A equipe cadastra uma vez e atualiza quando quiser.

Wix CMS Collection

O grid que se monta sozinho

O Repeater puxa os cases do CMS e monta o grid dos Conceitos 1 e 2 automaticamente. Adicionou um case novo no cadastro, ele aparece na hora.

Repeater + Dataset

Filtros por tipo de evento

As abas de filtro (Convenções, Premiações, Missões) usam o filtro nativo do Wix por categoria. O visitante encontra rápido o que interessa.

Filtros / User Input

Página de cada case

O Conceito 3 é uma Página Dinâmica: um único layout que vira a página de qualquer case, preenchido com os dados daquele registro. Bom para SEO e para o Google achar os cases.

Dynamic Pages

Movimento e hover

O zoom na imagem, o resultado que aparece no hover e a entrada suave ao rolar a página usam as interações e animações nativas do Wix Studio.

Hover + Scroll Effects

Vídeo em destaque

Os vídeos podem rodar em autoplay silencioso no card ou abrir em um Lightbox ao clicar no play, mantendo o padrão atual, só que mais elegante.
