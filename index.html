VIABILIDADE

Como isso fica no Wix Studio

Tudo aqui usa recursos nativos do Wix Studio. Nada depende de código externo pesado. A base é um único lugar para cadastrar os cases (CMS), e o resto se monta sozinho.

Um cadastro de cases (CMS)

Uma coleção no CMS do Wix com os campos de cada case: capa, vídeo, categoria, cliente, local, ano, números e textos. A equipe cadastra uma vez e atualiza quando quiser.

Wix CMS Collection

O grid que se monta sozinho

O Repeater puxa os cases do CMS e monta o grid automaticamente. Adicionou um case novo no cadastro, ele aparece na hora, no mesmo layout.

Repeater + Dataset

Filtros por tipo de evento

As abas de filtro (Convenções, Premiações, Missões) usam o filtro nativo do Wix por categoria. O visitante encontra rápido o que interessa.

Filtros / User Input

Movimento e hover

O zoom na imagem, o resultado que aparece no hover e a entrada suave ao rolar a página usam as interações e animações nativas do Wix Studio.

Hover + Scroll Effects

Vídeo em destaque

Os vídeos podem rodar em autoplay silencioso no card ou abrir em um Lightbox ao clicar no play, mantendo o padrão atual, só que mais elegante.
