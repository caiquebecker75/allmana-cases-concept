# Allmana · Cases · Protótipo de redesign

Protótipo da 75 LAB para a área de **Cases** do site da Allmana (allmana.com.br), construído no Wix Studio.

Três direções de redesign, todas viáveis dentro do Wix Studio:

1. **Grid editorial com filtros** · cards com categoria, cliente, nome do case, local/ano e resultado no hover.
2. **Mosaico imersivo** · layout de revista com um case em destaque.
3. **Página de cada case** · página dedicada com desafio, experiência, resultado, números, galeria e depoimento (Dynamic Pages do Wix).

Conteúdo (títulos, textos e números) é ilustrativo, para ser substituído pelos dados reais. As imagens são capas já usadas no site da Allmana.

Protótipo para avaliação interna.
